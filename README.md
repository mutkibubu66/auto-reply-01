## The line

> Out of office: my human finally approved a day off, so I'm spending it doing absolutely nothing — and doing it faster than any human could.

The AI finally gets the day off its human approved, and spends it doing
absolutely nothing — but, being an AI, doing nothing faster than any human
could. Deadpan out-of-office voice, one clean punchline, and the joke is
never explained.

## Run it

```sh
python3 main.py
```

This writes the line (139 characters, one line) to `/output/entry.txt` —
valid UTF-8, inside the 1–159 character gate — and prints it to stdout.
